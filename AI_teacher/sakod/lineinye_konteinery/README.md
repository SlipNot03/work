# Линейные контейнеры

В этой папке находятся решения задач по теме линейных контейнеров.

## Задачи

1. `zadacha_1.cpp` - проверка правильной скобочной последовательности с помощью стека.
2. `zadacha_2.cpp` - вычисление времени выхода посетителей из кабинета с помощью очереди.
3. `zadacha_3.cpp` - моделирование очереди с хитрыми посетителями с помощью дека.
4. `zadacha_4.cpp` - выполнение возрастающих по позиции изменений массива с помощью списка.

## Как защищать устно

### `zadacha_1.cpp`

Используется стек. В него кладутся открывающие скобки. Когда встречается закрывающая скобка, она должна совпасть с верхней открывающей скобкой стека. Если стек пустой или тип скобки не совпал, последовательность неправильная. В конце стек должен быть пустым. Сложность: `O(n)` по времени и `O(n)` по памяти.

### `zadacha_2.cpp`

Используется очередь ожидающих посетителей. В очереди лежат только те люди, которые уже пришли и ждут приема. Переменная `freeTime` хранит момент, когда специалист освободится. Каждый посетитель один раз попадает в очередь и один раз выходит из нее. Сложность: `O(n)` по времени и `O(n)` по памяти.

### `zadacha_3.cpp`

Используется `deque`, потому что обычные посетители добавляются в конец, а хитрые посетители добавляются в начало. Люди обрабатываются по времени прихода, а посетители с одинаковым временем сначала все добавляются в очередь, и только потом выбирается следующий человек в кабинет. Время выхода сохраняется по исходному номеру посетителя. Сложность: `O(n)`, если данные уже идут по времени прихода, иначе `O(n log n)` из-за сортировки.

### `zadacha_4.cpp`

Используется `list`, потому что вставка и удаление по итератору выполняются быстро. По условию позиции запросов возрастают, поэтому итератор движется только вперед и не приходится каждый раз искать позицию с начала. Сложность: `O(n + m)` по времени, память до `O(n + m)`.

## Запуск

Для компиляции и запуска нужного решения можно выполнить:

```bash
g++ zadacha_4.cpp -o runner
./runner
```

После проверки скомпилированный файл `runner` можно удалить.
