# Линейные алгоритмы

В этой папке находятся решения задач по теме линейных алгоритмов.

## Задачи

1. `zadacha_1.cpp` - ответы на запросы суммы на отрезке с помощью префиксных сумм.
2. `zadacha_2.cpp` - ответы на запросы произведения на отрезке с помощью префиксных произведений и обратного элемента.
3. `zadacha_3.cpp` - поиск подотрезка с максимальной суммой за один проход.
4. `zadacha_4.cpp` - поиск минимума в каждом окне фиксированной длины с помощью дека.

## Как защищать устно

### `zadacha_1.cpp`

Используется массив префиксных сумм. `prefix[i]` хранит сумму первых `i` элементов. Сумма на отрезке `[L, R]` считается как `prefix[R] - prefix[L - 1]`. Сложность: `O(n + m)` по времени и `O(n)` по памяти.

### `zadacha_2.cpp`

Используется массив префиксных произведений по модулю. Произведение на отрезке формально считается делением `prefix[R] / prefix[L - 1]`, но деление по модулю заменяется умножением на обратный элемент. Обратный элемент находится расширенным алгоритмом Евклида. Сложность: `O(n + m log MOD)` по времени и `O(n)` по памяти.

### `zadacha_3.cpp`

Используется алгоритм Кадане. Хранится сумма текущего выгодного подотрезка. Если она стала `<= 0`, продолжать ее невыгодно, поэтому новый подотрезок начинается с текущей позиции. Лучший ответ обновляется только при строго большей сумме. Сложность: `O(n)` по времени и `O(1)` по памяти.

### `zadacha_4.cpp`

Используется монотонный `deque` индексов. Перед добавлением нового элемента из конца удаляются элементы больше или равные ему, потому что они уже не смогут стать минимумом. Из начала удаляются индексы, вышедшие из окна. Минимум всегда находится в начале дека. Сложность: `O(n)` по времени.

## Запуск

Для компиляции и запуска нужного решения можно выполнить:

```bash
g++ zadacha_4.cpp -o runner
./runner
```

После проверки скомпилированный файл `runner` можно удалить.
