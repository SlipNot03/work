# Рекурсия. Перебор

В этой папке находятся решения задач по теме рекурсии и перебора.

## Задачи

1. `zadacha_1.cpp` - вычисление факториала числа рекурсивной функцией.
2. `zadacha_2.cpp` - вычисление числа Фибоначчи рекурсивной функцией с запоминанием.

## Как защищать устно

### `zadacha_1.cpp`

Факториал считается рекурсивно. Базовый случай: `factorial(1) = 1`. Для остальных значений функция возвращает `n * factorial(n - 1)`, постепенно сводя задачу к меньшему аргументу. Сложность: `O(n)` по времени и `O(n)` по памяти из-за стека рекурсии.

### `zadacha_2.cpp`

Число Фибоначчи считается рекурсивно по формуле `F(n) = F(n - 1) + F(n - 2)`. Чтобы не пересчитывать одни и те же значения много раз, используется массив `saved`. Если значение уже посчитано, функция сразу его возвращает. Сложность: `O(n)` по времени и `O(n)` по памяти.

## Запуск

Для компиляции и запуска нужного решения можно выполнить:

```bash
g++ zadacha_2.cpp -o runner
./runner
```

После проверки скомпилированный файл `runner` можно удалить.
