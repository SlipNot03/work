# osvidetelstvovanie_kwork

Лендинг по ТЗ заказчика для услуги психиатрического освидетельствования продавца перед сделкой.

## Что реализовано

- 10 смысловых блоков по тексту ТЗ.
- Мобильная закрепленная панель связи: консультация, звонок, MAX, Telegram.
- Мобильная шапка: логотип, кнопка меню, скрытая навигация.
- Формы с полями: имя, телефон, комментарий.
- Передача типа заявки через скрытое поле `orderType`.
- Заготовки целей: заявка, звонок, мессенджеры.
- Телефоны, почта и быстрые ссылки из ТЗ.

## Настройка Метрики

В `script.js` заполнить:

```js
const METRIKA_ID = "12345678";
```

Цели:

- `lead_submit`
- `call_click`
- `messenger_click`

## Отправка заявок

В статической версии заявка выводится в консоль. В Tilda нужно подключить стандартный прием заявок на почту `alcocod1@yandex.ru` или заменить обработчик формы на webhook.
