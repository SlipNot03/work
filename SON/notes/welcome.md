# SON v0.2 Notes

This folder is the first read-only personal knowledge area for SON Assistant.

Put Markdown, text, or reStructuredText files here. The backend indexes these files
for search and can attach relevant excerpts to chat requests as grounded context.

Safety rule for v0.2: the assistant may read indexed excerpts from this folder, but
it cannot edit, delete, execute, or move files.
