# Asset Guide - ECNG Invoicing

To maintain the "Futuristic Premium" look, use high-quality assets:

## 1. Images & Mockups
- **Hero Image:** Should be a high-resolution dashboard screenshot or a 3D abstract object (glass/crystal) in `.webp` format.
- **Audience Image:** A subtle, dark-themed photo of a modern office or a "glassmorphism" card showing a P&L graph.
- **Lazy Loading:** All images should use `loading="lazy"` attribute.

## 2. Icons
- Use **SVG** only. 
- Recommendation: [Lucide Icons](https://lucide.dev/) or [Phosphate Icons].
- Inline SVG is preferred for performance and easy styling via CSS `fill` or `stroke`.

## 3. Favicon
- `favicon.ico` (Standard)
- `icon.svg` (Modern browsers)
- `apple-touch-icon.png` (iOS)

## 4. Logo
- Use a text-based logo (as in `index.html`) or a simple geometric SVG logo for maximum sharpness on 4K screens.
