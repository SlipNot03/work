Design System
Background: Dark Graphite/Black (#07080A)
Glass Panels: White with 3-5% opacity + Backdrop Blur
Primary Accent: Neon Teal (#00F0B5)
Secondary Accent: Cyan Blue (#00D4FF)
Typography: System UI fonts (Inter, Roboto Mono for data/numbers if available, falling back to system defaults).
No heavy images, videos, or 3D renders are required for this design concept, keeping the deployment lightweight and the load time instantaneous.
