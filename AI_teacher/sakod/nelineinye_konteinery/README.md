# Нелинейные контейнеры

В этой папке находятся решения задач по теме нелинейных контейнеров.

## Задачи

1. `zadacha_1.cpp` - поиск различных чисел с помощью множества `set`.
2. `zadacha_2.cpp` - замена фамилий в тексте с помощью словаря `map`.
3. `zadacha_3.cpp` - поиск самого короткого отрезка со всеми числами от 1 до K с помощью `map`.

## Как защищать устно

### `zadacha_1.cpp`

Используется `set`, потому что он хранит только уникальные значения и автоматически выводит их в порядке возрастания. Все числа вставляются в множество, затем выводится размер множества и его элементы. Сложность: `O(n log n)` по времени и `O(k)` по памяти, где `k` - количество различных чисел.

### `zadacha_2.cpp`

Используется `map<string, string>`, где ключ - старая фамилия, а значение - новая фамилия. Текст читается до конца входного потока, каждое слово проверяется в словаре замен. Если слово найдено, выводится новая фамилия, иначе слово остается без изменений. Сложность: `O((n + w) log n)`, где `w` - количество слов.

### `zadacha_3.cpp`

Сначала `K` определяется как максимум в массиве. Затем используется метод двух указателей: правая граница расширяет отрезок, левая сжимает его, когда внутри есть все числа от `1` до `K`. В `map` хранятся счетчики чисел в текущем окне. Сложность: `O(n log k)` по времени и `O(n + k)` по памяти.

## Запуск

Для компиляции и запуска нужного решения можно выполнить:

```bash
g++ zadacha_3.cpp -o runner
./runner
```

После проверки скомпилированный файл `runner` можно удалить.
