# Поиск

В этой папке находятся решения задач по теме поиска.

## Задачи

1. `zadacha_1.cpp` - определение минимального числа вопросов для угадывания числа бинарным поиском.
2. `zadacha_2.cpp` - нахождение квадратного корня вещественным двоичным поиском.
3. `zadacha_3.cpp` - поиск точки минимума параболы на отрезке тернарным поиском.

## Как защищать устно

### `zadacha_1.cpp`

Каждый вопрос с ответом `YES` или `NO` делит множество возможных чисел примерно пополам. После `q` вопросов можно различить до `2^q` вариантов, поэтому ищется минимальное `q`, при котором `2^q >= N`. Сложность: `O(log N)` по времени и `O(1)` по памяти.

### `zadacha_2.cpp`

Корень ищется вещественным двоичным поиском. Поддерживается отрезок, где находится ответ. Если `middle * middle <= X`, левая граница сдвигается вправо, иначе правая граница сдвигается влево. После фиксированного числа итераций получается нужная точность. Сложность: `O(1)` при фиксированных 200 итерациях.

### `zadacha_3.cpp`

Для параболы ветвями вверх применяется тернарный поиск: берутся две внутренние точки, сравниваются значения функции и отбрасывается часть отрезка без минимума. Если `A < 0`, парабола направлена вниз, поэтому минимум на отрезке находится на одном из концов. Сложность: `O(1)` при фиксированном числе итераций.

## Запуск

Для компиляции и запуска нужного решения можно выполнить:

```bash
g++ zadacha_3.cpp -o runner
./runner
```

После проверки скомпилированный файл `runner` можно удалить.
