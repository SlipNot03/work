# Основы теории графов

В этой папке находятся решения задач по теме основ теории графов.

## Задачи

1. `zadacha_1.cpp` - преобразование графа между матрицей смежности, списком смежности и списком ребер.
2. `zadacha_2.cpp` - подсчет компонент связности в графе обходом в ширину.
3. `zadacha_3.cpp` - вычисление времен входа и выхода вершин при обходе в глубину.
4. `zadacha_4.cpp` - поиск любого цикла в неориентированном графе обходом в глубину.
5. `zadacha_5.cpp` - поиск кратчайших расстояний от заданной вершины обходом в ширину.
6. `zadacha_6.cpp` - поиск самого длинного кратчайшего пути в дереве двумя обходами BFS.
7. `zadacha_7.cpp` - поиск маршрута с минимальным штрафом в графе с ребрами веса 0 и 1.

## Как защищать устно

### `zadacha_1.cpp`

Граф сначала приводится к матрице смежности. Для неориентированного графа при ребре `u-v` заполняются обе ячейки: `graph[u][v]` и `graph[v][u]`. Из матрицы затем выводятся две другие формы представления. Сложность: `O(n^2 + m)` по времени и `O(n^2)` по памяти.

### `zadacha_2.cpp`

Компоненты связности считаются обходом BFS. Если вершина еще не посещена, начинается новый BFS, а счетчик компонент увеличивается. BFS посещает все вершины текущей компоненты. Сложность: `O(n^2)` по времени, потому что граф задан матрицей.

### `zadacha_3.cpp`

Используется DFS. При первом входе в вершину увеличивается таймер и записывается время входа. После обработки всех соседей таймер увеличивается еще раз и записывается время выхода. Если граф несвязный, DFS запускается из каждой непосещенной вершины. Сложность: `O(n + m)`.

### `zadacha_4.cpp`

Цикл ищется DFS с цветами и массивом родителей. Если из текущей вершины есть ребро в уже открытую вершину, которая не является родителем, найден цикл. Сам цикл восстанавливается проходом назад по `parent`. Сложность: `O(n^2)` по времени и памяти, потому что используется матрица смежности.

### `zadacha_5.cpp`

Кратчайшие расстояния в невзвешенном графе находятся BFS. Стартовая вершина имеет расстояние `0`, соседи получают расстояние `1`, следующие вершины - `2` и так далее. Очередь обрабатывает вершины по слоям, поэтому первое найденное расстояние минимально. Сложность: `O(n + m)`.

### `zadacha_6.cpp`

Так как граф является деревом, самый длинный кратчайший путь - это диаметр дерева. Первый BFS из любой вершины находит один конец диаметра, второй BFS из этого конца находит второй конец и родителей для восстановления пути. Сложность: `O(n + m)` по времени и памяти.

### `zadacha_7.cpp`

Используется `0-1 BFS`. Ребра веса `0` добавляют вершину в начало дека, ребра веса `1` - в конец, поэтому минимальный штраф считается корректно. Затем путь восстанавливается с выбором наименьшей подходящей следующей вершины, чтобы получить лексикографически минимальный маршрут среди маршрутов с минимальным штрафом.

## Запуск

Для компиляции и запуска нужного решения можно выполнить:

```bash
g++ zadacha_7.cpp -o runner
./runner
```

После проверки скомпилированный файл `runner` можно удалить.
