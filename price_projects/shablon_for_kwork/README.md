# shablon_for_kwork

Статический квиз-лендинг для ниши ремонта квартир и помещений под трафик из Яндекс Директ.

## Что внутри

- `index.html` - структура лендинга и форма квалификации.
- `styles.css` - адаптивная стилизация без внешних библиотек.
- `script.js` - квиз, расчет диапазона стоимости, UTM, подмена телефона и отправка лида.
- `assets/` - локальные визуальные материалы.

## Как подключить CRM

В файле `script.js` укажите URL webhook:

```js
const CRM_WEBHOOK_URL = "https://example.com/webhook";
```

Сейчас, если URL пустой, заявка не уходит наружу, а выводится в консоль браузера.

## Коллтрекинг

В `TRACKING_PHONES` можно заменить номера на номера Calltouch, CoMagic, Roistat или другого сервиса. Скрипт уже читает `utm_source` и `utm_medium`.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер из этой папки:

```bash
python3 -m http.server 8080
```
