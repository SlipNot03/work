Distribution
Составляет статистическое распределение: сортирует данные, считает, сколько раз встретилось каждое значение, и печатает пары значение - частота.

Interval
Считает относительные частоты. Для каждого значения берет его частоту и делит на объем выборки.

Gistogramm
Строит графическое представление частот через matplotlib. В среде без GUI может появляться предупреждение FigureCanvasAgg.

FuncDistribution
Печатает эмпирическую функцию распределения. Она показывает накопленную долю наблюдений по мере движения слева направо по значениям.

GrafFuncDistr
Строит график эмпирической функции распределения. Обычно он ступенчатый, потому что функция меняется только в точках наблюдений.

MainCheracter
Считает основные числовые характеристики: выборочное среднее, дисперсию, среднее квадратическое отклонение и коэффициент вариации.

Help
Содержит GetData(data_x, data_p): разворачивает интервальный/частотный ряд в обычную выборку, повторяя каждое значение нужное число раз.

Laplas
Хранит табличные значения функции Лапласа и помогает получать параметры для доверительных интервалов и Z-критериев.

t_crit
Хранит табличные критические значения распределения Стьюдента.

Fisher
Хранит/возвращает критические значения критерия Фишера для проверки равенства дисперсий.

Spirman
Содержит критические значения для коэффициента ранговой корреляции Спирмена.

Pirson
Содержит функции проверки гипотез о нормальном и равномерном распределении с использованием scipy.stats.

my_methods
Самый крупный вспомогательный файл: содержит функции для распределений, хи-квадрат, корреляции Пирсона, уравнений регрессии, критических значений и других расчетов.
