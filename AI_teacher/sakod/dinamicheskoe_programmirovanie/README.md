# Динамическое программирование

В этой папке находятся решения задач по теме динамического программирования.

## Задачи

1. `zadacha_1.cpp` - подсчет способов подняться по лестнице прыжками длиной не больше K.
2. `zadacha_2.cpp` - вычисление числа Фибоначчи динамическим программированием.

## Как защищать устно

### `zadacha_1.cpp`

`dp[i]` хранит количество способов попасть на ступеньку `i`. Чтобы попасть на `i`, последним прыжком можно прийти с `i - 1`, `i - 2`, ..., `i - K`, если такая ступенька существует. Поэтому `dp[i]` считается как сумма этих значений по модулю. Сложность: `O(n * k)` по времени и `O(n)` по памяти.

### `zadacha_2.cpp`

`dp[i]` хранит число Фибоначчи `F(i)`. Начальные значения: `dp[0] = 0`, `dp[1] = 1`. Дальше каждое значение считается как сумма двух предыдущих: `dp[i] = dp[i - 1] + dp[i - 2]` по модулю. Сложность: `O(n)` по времени и `O(n)` по памяти.

## Запуск

Для компиляции и запуска нужного решения можно выполнить:

```bash
g++ zadacha_2.cpp -o runner
./runner
```

После проверки скомпилированный файл `runner` можно удалить.
