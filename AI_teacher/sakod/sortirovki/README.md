# Сортировки

В этой папке находятся решения задач по теме сортировок.

## Задачи

1. `zadacha_1.cpp` - сортировка чисел вставками по количеству цифр `5`.
2. `zadacha_2.cpp` - пирамидальная сортировка по невозрастанию через min-heap.

## Как защищать устно

### `zadacha_1.cpp`

Реализована сортировка вставками. Левая часть массива считается уже отсортированной, а очередной элемент вставляется в нужное место. Сравнение идет сначала по количеству цифры `5` по невозрастанию, затем по значению числа по невозрастанию. Сложность: `O(n^2)` по времени и `O(1)` дополнительной памяти.

### `zadacha_2.cpp`

Реализована пирамидальная сортировка через min-heap. В корне кучи хранится минимальный элемент. На каждом шаге минимум меняется с последним элементом текущей кучи и уходит в конец массива, поэтому итоговый порядок получается по невозрастанию. Сложность: `O(n log n)` по времени и `O(1)` дополнительной памяти.

## Запуск

Для компиляции и запуска нужного решения можно выполнить:

```bash
g++ zadacha_2.cpp -o runner
./runner
```

После проверки скомпилированный файл `runner` можно удалить.
